Minecraft Uploader

Wähle eine lokal gespeicherte Minecraft-Welt, verbinde deinen Server und lade sie hoch – die App zeigt vorher, ob die Welt zur Serverversion passt.

⬇ Herunterladen Quellcode auf GitHub
v1.0.0 · macOS (Apple Silicon und Intel) · Windows · kostenlos, MIT-Lizenz

So läuft es ab

  1. WeltenDie App findet alle Java-Welten im Ordner .minecraft/saves – mit Icon, Version, Spielmodus, Größe und letztem Spiel.
  2. ServerServer hinzufügen (SFTP, FTP oder lokaler Ordner). Die App zeigt Status, Version, Spieler und die Einstellungen aus der server.properties.
  3. PrüfenJede Welt bekommt eine Kompatibilitätsanzeige für den gewählten Server.
  4. HochladenMit Fortschrittsanzeige; auf Wunsch wird die Welt direkt als level-name eingetragen.

Funktionen

Kompatibilität

Verglichen werden das Weltformat (DataVersion aus der level.dat) und die Version des Servers. Welten, die neuer sind als der Server, werden gesperrt; ältere werden als „wird aktualisiert“ markiert.

Server-Specs

Online-Status, Antwortzeit, Version, Spielerzahl, MOTD sowie Spielmodus, Schwierigkeit, Sichtweite und Whitelist aus der server.properties.

SFTP, FTP oder lokal

Zugang per Passwort oder SSH-Schlüssel. Läuft der Server auf demselben Rechner, genügt ein Ordner.

Sicher

Passwörter werden mit dem Schlüsselbund des Betriebssystems verschlüsselt gespeichert. Der Upload überschreibt nie eine vorhandene Welt auf dem Server.

Gut zu wissen

  • Nur Java Edition. Bedrock-Welten (iPad, Konsole, Windows 10/11 Edition) werden erkannt, aber nicht hochgeladen.
  • Server stoppen. Beende den Server vor dem Upload und starte ihn danach neu, damit die Welt geladen wird.
  • Neuere Versionen. Mods, Plugins und Datapacks prüft die App nicht. Für sehr neue Minecraft-Versionen muss die Versionstabelle src/lib/versions.js ergänzt werden.
  • SmartScreen / Gatekeeper: Die Programme sind nicht code-signiert. Windows zeigt „Weitere Informationen → Trotzdem ausführen“, macOS fragt beim ersten Start (Rechtsklick → Öffnen).
